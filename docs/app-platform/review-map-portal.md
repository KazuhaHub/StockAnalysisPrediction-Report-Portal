# Portal platform review map

This map orders the `internal/app` changes in the Portal platform slice for review. A file-level reference analysis grouped them; each group depends only on groups above it, except that the core is one cycle. File lists are exhaustive.

## 1. Core

The control store and schema (migrations 0015–0020), operation leases and fences, publisher trust, actors and principals, runtime bindings, review plans, and the managed install, enable and update reviews. These 84 files reference each other in one cycle, so read them as one unit. Start with `app_platform_schema.go`, `app_platform_lease.go`, `app_platform_trust.go`, `app_platform_actor.go`, `app_platform_runtime.go` and `app_platform_removal_review.go`; most other files build on these.
