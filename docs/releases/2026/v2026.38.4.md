# v2026.38.4

## Audit log readability

- Keep IP addresses on the first line and country flags with location names on the second line, consistently across desktop and mobile audit views.
- Show API key notes as the actor label for new token-authenticated audit records. Notes are saved with the event and remain available after the key is deleted.
- Preserve the generic API token label for older records and keys without a note. Historical records without token identity cannot be backfilled reliably.

No database schema changes are required.
