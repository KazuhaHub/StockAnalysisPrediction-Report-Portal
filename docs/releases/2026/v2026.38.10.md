# v2026.38.10

This full release consolidates the reader-visible changes published in the Beta builds since
v2026.38.

## Update delivery

- Add an automatic policy that refreshes open pages when a new build is ready and confirms the
  loaded version afterward.
- Fall back to a closable update dialog and then a persistent site-wide banner when an automatic
  refresh cannot load the target build, without entering a reload loop.
- Keep the existing dismissible and persistent reminder policies available for sites that do not
  want automatic refreshes.

## Version and release history

- Let signed-in readers open the running build's release notes from its version label and browse the
  recent packaged history without GitHub access.
- Show full-release milestones in stable builds. Beta builds additionally show the Beta changes
  published after the latest full release, so superseded Beta notes do not duplicate the stable
  summary.
- Give the version list and release-note content independent scrolling areas on desktop and label
  entries with compact `Stable`, `Beta`, or `Dev` tags.
- Open release history without refreshing the page, showing an update-policy warning, or moving a
  long page back to the top.
- Let administrators hide the reader-facing version label, keep it in the footer by default, or
  place it beside the site name. The sign-in page never displays a version, and the management
  console always retains its diagnostic version entry.

## Audit log readability

- Keep IP addresses on the first line and country flags with location names on the second line on
  desktop and mobile.
- Show an API key's saved note as the actor label for new token-authenticated audit events, including
  after that key is deleted, while retaining the generic label for older records and unnamed keys.

## Compatibility

This release requires the v0.4.72 database schema, as every CalVer release does. No database schema
changes are required from v2026.38 or any Beta in this series.
