# v2026.38.11

This full release makes GitHub Release the live source for update history and release maturity.

## Live release history

- Read update notes and `Stable` / `Beta` status from the current published GitHub Release instead
  of freezing them into each binary at build time.
- Reflect a later promotion or demotion of the same Release without changing its tag, rebuilding its
  artifacts, or replacing its fixed container image.
- Keep the portal responsive during a temporary GitHub outage by retaining only the last successful
  response and marking it stale until the next refresh succeeds.

## Reader-focused update notes

- Show only the reader-facing changelog in the in-portal update dialog. Container pull commands,
  checksum verification and GitHub's generated pull-request list remain on the Release page.
- Apply the same separation to existing Release bodies that predate the explicit reader-note
  boundary, so historical dialogs do not expose deployment instructions.

## Compatibility

This release requires the v0.4.72 database schema, as every CalVer release does. No database schema
changes are required from v2026.38 or any later release.
